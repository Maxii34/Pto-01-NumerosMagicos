# 🎮 Juego: Adivina el Número Mágico

Este es un sencillo juego interactivo desarrollado con **HTML**, **CSS (Bootstrap)** y **JavaScript**, donde el usuario debe adivinar un número aleatorio generado por el programa.

---

## 🧩 Funcionalidades

- Generación de un número mágico al hacer clic en **"Comenzar el juego"**.
- Campo de entrada para que el usuario ingrese su intento.
- Botón **Enviar** que compara el número ingresado con el número mágico.
- Alertas que indican si el número es:
  - Correcto ✅
  - Mayor ❌
  - Menor ❌

---

## 🛠️ Tecnologías Utilizadas

| Tecnología      | Uso Principal                  |
|----------------|--------------------------------|
| HTML5          | Estructura básica del sitio    |
| Bootstrap 5    | Estilos y diseño responsivo    |
| JavaScript     | Lógica del juego               |

## 🚀 Cómo Ejecutar el Proyecto

1. Abre el archivo `index.html` con tu navegador.
2. Haz clic en **"Comenzar el juego"**.
3. Ingresa números y usa el botón **"Enviar"** hasta adivinar el número mágico.
